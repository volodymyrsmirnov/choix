# Deferred and out of scope

What Choix 2.0 deliberately does not do. Each item is either a non-goal of the
design (`docs/superpowers/specs/2026-11-11-choix-2-desktop-design.md`, §2, and
`docs/superpowers/specs/2026-11-12-builtin-grouping-and-quality-design.md`,
§3 and §14) or something left for later until the owner decides. Don't build any of
it without renegotiating the scope first.

## Not planned

- **Intel Macs, Linux, Windows.** Choix is macOS on Apple Silicon only, and
  there is no universal binary (hard rule 5).
- **The command-line tool, the HTTP server and the browser UI of Choix 1.x.**
  They were removed; the desktop app is the only interface.
- **Importing 1.x settings** (`~/.choix/config.toml`). A sandboxed app cannot
  read them.
- **Anything outside the App Sandbox:** private APIs (and with them window
  translucency), temporary-exception entitlements, helper executables
  (hard rule 8).
- **Any network access**, telemetry included (hard rule 6), and any
  downloaded or bundled model.
- **Acting on the analysis.** No auto-pick, no rerank, no "best in cluster"
  marker; the feature print groups, the quality rating is a number, and the
  user's pick is the source of truth.
- **Text search and person grouping.**

## Left for later

- **State for read-only folders.** A folder on a read-only volume (a locked SD
  card) is reported as such; Choix does not keep its `.choix/` state anywhere
  else (spec §6).
- **Single-key shortcuts in the native menu.** Space, X, the arrows, C, Z, I
  and ? stay with the webview and are listed in the shortcut sheet until the
  owner has verified, by hand, that the menu can own them without stealing
  typing (spike S2; `menu.NativeAccelerator`).
- **The hardened runtime for ad hoc builds** (`sign:dev`); the Developer ID
  build has it.
- **A quality presentation that fits what the score means**: flags such as
  soft, noisy, dark or blown out, or a mark relative to the cluster, instead of
  one number that only compares frames of the same scene.
- **Subject-aware sharpness, face checks and Vision's aesthetics score** for
  the rating. Vision can do them; none helped the score when measured.
- **Threshold help.** Similarity thresholds do not transfer between kinds of
  shooting; a per-folder suggestion would help.
- **More validation of the grouping** on labelled folders, and of
  cross-device merging (its 0.93 anchor) on real two-camera data.
- **An Icon Composer asset catalog.** The bundle ships `choix.icns`; an
  `Assets.car` is added when the owner provides the `.icon` file (plan call C27).
