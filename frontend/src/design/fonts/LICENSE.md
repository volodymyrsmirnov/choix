# Bundled fonts

The `woff2` files in this folder are the latin subsets copied from the
Fontsource npm packages pinned in `frontend/package.json`. They are bundled so
no font request leaves `localhost`.

| Files | Family | Source | Licence |
|---|---|---|---|
| `inter-latin-{400,500,600,700}.woff2` | Inter | `@fontsource/inter` 5.3.0 | SIL Open Font License 1.1. Copyright 2016 The Inter Project Authors (https://github.com/rsms/inter) |
| `jetbrains-mono-latin-{400,500}.woff2` | JetBrains Mono | `@fontsource/jetbrains-mono` 5.3.0 | SIL Open Font License 1.1. Copyright 2020 The JetBrains Mono Project Authors (https://github.com/JetBrains/JetBrainsMono) |

The full licence text is at https://openfontlicense.org and in each package's
`LICENSE` file.
